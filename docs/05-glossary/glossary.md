# Глосарій

| Термін | Визначення |
|---|---|
| **Бібліотекар** | Працівник бібліотеки, єдиний користувач системи |
| **Читач** | Зареєстрований відвідувач бібліотеки, якому видають книги |
| **Номер читацького квитка** | Унікальний номер читача у форматі `Ч-NNNN`, присвоюється автоматично |
| **Книга** | Запис у каталозі (назва, автор, рік, жанр, ISBN) разом із кількістю примірників |
| **Жанр** | Категорія книги (роман, поезія тощо), за якою можна фільтрувати каталог |
| **Примірник** | Один фізичний екземпляр книги |
| **Вільний примірник** | Примірник, який зараз не на руках у читача |
| **Видача** | Запис про те, що книгу передано читачеві на певний термін |
| **Термін повернення** | Дата, до якої читач має повернути книгу: дата видачі + кількість днів |
| **Прострочена видача** | Неповернена видача, термін повернення якої вже минув |
| **Боржник** | Читач, у якого є хоча б одна прострочена видача |
| **ISBN** | Міжнародний стандартний номер книги |
| **FR / NFR** | Функціональна / нефункціональна вимога |
| **Use case (UC)** | Варіант використання: дії актора й системи для досягнення мети |
| **ER-модель** | Модель даних: сутності, їхні атрибути та звʼязки |
